# Installing grimoire for Pi

grimoire-core is a [Pi package](https://pi.dev/packages). Its root `package.json`
lists every nested skills folder under the `pi` key (generated by
`make update-plugin-manifest`):

```json
"pi": { "skills": ["./skills/art/color-theory/skills", "..."] }
```

## Install

```bash
pi install git:github.com/jeffreytse/grimoire-core
```

Pin a release with `@<tag>`, e.g. `pi install git:github.com/jeffreytse/grimoire-core@v0.1.0`.

Local checkout:

```bash
git clone https://github.com/jeffreytse/grimoire-core
pi install ./grimoire-core
```

## Usage

Pi lists each skill by name and description and loads it on demand. Invoke one
explicitly with `/skill:<name>`, for example:

```text
/skill:propose-conventional-commit
```

## Notes

- The package ships skills only — no Pi extension, so tools a skill names
  (`Skill`, `Agent`, `TodoWrite`) map to Pi's native equivalents or are skipped.
- Skills-only alternative: Pi also reads `~/.agents/skills/`, which
  `grimoire install --target agent` populates.
